# AlmostThere

**AlmostThere** tells you which achievements to go for next.

Instead of scrolling through thousands of achievements, AlmostThere lists the ones you can finish with the least effort, ranked easiest first. Each achievement has a pre-built effort rating, and the ranking is adjusted for how far along you already are.

## Features

- **Easiest-first recommendations**: incomplete achievements ranked by effort, adjusted for your current progress.
- **Search**: find a specific achievement quickly.
- **Bookmarks**: pin the achievements you want to work on and track them in a small panel.
- **Filters**: narrow the list by expansion and by effort level
- **Stays current**: the list refreshes when you earn an achievement or your progress changes.


## Usage

- `/almostthere` or `/almostthere top [n]`: print the n easiest achievements in chat
- `/almostthere results`: open the recommendations window
- `/almostthere scan`: rescan your progress and re-evaluate effort

Or just click the minimap button.

## Notes

- Ratings are estimates, so treat them as a guide.
