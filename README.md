# AlmostThere

World of Warcraft addon that recommends the easiest incomplete achievements using pre-built effort ratings, adjusted for your progress.

## Layout

- `AlmostThere/` – the addon itself (this is what ships)
- `media/` – source art for the addon icon

`Data/Ratings.lua` is generated by the separate AlmostThere-tools repo (expected as a sibling checkout), which also holds the release script.

## Releasing

1. Add a `## X.Y.Z` section to `CHANGELOG.md` and commit it.
2. `../AlmostThere-tools/release.sh X.Y.Z --dry-run` to check the zip in `dist/`.
3. `CF_API_KEY=... ../AlmostThere-tools/release.sh X.Y.Z --upload` to bump the TOC version, commit, tag and upload to CurseForge (requires `X-Curse-Project-ID` in the TOC).
4. `git push origin main --follow-tags`.

Requires `bash`, `git`, `python3`, `jq`, `curl`.
